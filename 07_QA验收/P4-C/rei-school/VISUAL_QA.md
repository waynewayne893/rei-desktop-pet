# 校服方向候选视觉复检

校服先从冻结派生母版生成一批四基准方向，确认抬头、屏幕右转、低头和屏幕左转，再以同一母版和基准条带为参考生成四批过渡方向。每个方向的头部、眼睛和身体均来自原生透明生成条带。登记使用批次内等比缩放和平移。

| 批次 | 方向 | 有标签人工前复检观察 |
| --- | --- | --- |
| cardinals-attempt-01 | 000°、090°、180°、270° | 抬头、屏幕右转、低头和屏幕左转区分清楚。红瞳、双白发夹与交握姿态延续冻结母版。 |
| quad-ne-attempt-01 | 022.5°、045°、067.5° | 从上视到右视，头部上仰递减、右转逐步加强。 |
| quad-se-attempt-01 | 112.5°、135°、157.5° | 右转减弱、低头逐步加强。112.5° 与 090° 在原生尺寸较接近。 |
| quad-sw-attempt-01 | 202.5°、225°、247.5° | 低头逐步过渡到左转。202.5° 的偏左幅度较小。 |
| quad-nw-attempt-01 | 292.5°、315°、337.5° | 从左转逐步到左上视和接近正上。337.5° 回接 000°。 |

16 帧均通过结构门禁。192×208 RGBA 的可见实体高度为 186–189 px，测得脚底锚点 x 为 95.5–96.5、y 为 194–195。各原始条带边缘和分隔线 Alpha 均不超过 1。登记帧边界 Alpha 为 0，透明像素隐藏 RGB 为 0。

明暗底均查看全部 16 帧，未见显眼的独立残影；结构记录列出 16 个低 Alpha 独立分量，单个最多 15 像素，最高 Alpha 为 4/255。细微方向间距和服饰、头部连贯性仍待人工验收。
