# 黑服过渡方向｜制作检查

四个选用批次以冻结黑服母版和已验收的四基准方向条带为参考。全套保持黑红发饰、红瞳、胸口红色 09、青绿斜纹、正向躯干及右手扶左臂。每个方向来自对应原生 RGBA 图格，登记仅执行等比缩放和脚底平移。以下为制作检查，全部 12 帧仍待人工验收。

| 顺时针范围 | 选用批次 | 原图检查 |
| --- | --- | --- |
| 022.5°、045°、067.5° | upper-right-02 | 由以抬头为主逐步转为以向屏幕右侧偏头为主。022.5° 的右侧偏转较轻，建议人工对照 000° 看瞳孔位置。 |
| 112.5°、135°、157.5° | lower-right-01 | 右侧偏头逐步回到接近正面，低头幅度逐步增加，胸口 09 保持正读。 |
| 202.5°、225°、247.5° | lower-left-02 | 由以低头为主逐步转为以向屏幕左侧偏头为主。202.5° 接近 180°，建议结合对照检查轻微的左偏。 |
| 292.5°、315°、337.5° | upper-left-01 | 由以向屏幕左侧偏头为主逐步转为以抬头为主，非对称扶臂未随朝向翻转。 |
