# Rei Desktop Pet V1.0｜P3–P6 路线

启动条件为主控对 P2 作出独立裁定并授权进入下一阶段。三个产品独立构建、注册和选择。工作范围为 Codex 桌面 Pets。

## P3｜透明母版与尺寸适配

- [ ] 对照冻结清单扫描三张源图和备份哈希。已确认校服源是独立单人图。每张复杂边缘分别试验遮罩，派生 RGBA 输出到 `02_标准化母版/` 并记录输入哈希、算法、参数、输出哈希及源分辨率预览。
- [ ] 校服重点检查发尖、白袖、领结、双手间隙和白袜。白服重点检查浅背景与服装高光边界、指尖、00 及鞋尖。黑服检查扶臂遮挡、发饰、指尖、09 及鞋底边。脚下原画软影作为单独去留判断。
- [ ] 生成各角色一个 192×208 显示样本与明暗底对照，保留比例和脚底锚点。原尺寸与原生显示均过关后冻结三个标准化派生母版。记录可复用缩放、锚点、动作留白范围。
- [ ] 确认 P4 采用桌面 `hatch-pet` 版本，复核 `(0,6)` 中性参考格合同并记录工具版本。P3 验收止于三个静态派生样本。

## P4｜三套图集

- [ ] 在 `03_校服绫波丽/`、`04_白色战斗服/`、`05_黑色战斗服/` 分别保留原条带、处理帧、图集和来源记录。先做每套 idle 与右移，确认角色身份、稳定基线、周期动作及明暗底边缘，再完成九行动作。
- [ ] 校服表现安静、自然、柔和，待机保持交握，招呼小幅抬手后自然合回。白服强调沉静与专注，站姿待命，工作通过凝神和克制的头手变化表达。黑服保持疏离、懵懂，延迟小幅反应，基本姿态右手扶左臂。分开编排等待、失败、工作和查看。
- [ ] 九行组装 1536×1872 中间图。独立批准四个注视基准方向，以眼睛领动、头颈细微跟随、身体和脚底锚定。按随附工具先登记并验收行 9，再以相同变换处理行 10。
- [ ] 从验收 idle 提供辅助中性格。用当前装配器输出 1536×2288 WebP，各套 57 动作格、16 方向格、1 中性参考格。重新做缩放、裁切、减动静态帧和首尾连续性检查。

## P5｜QA、独立注册与运行

- [ ] 在 `07_QA验收/` 保存最终编码 SHA-256、随附 `validate_atlas.py --require-v2` 报告和结构证据。检查 14 个透明空格、明暗底边缘、运动 GIF、17 格中性与注视 QA、四基准方向盲检、跨行接缝与服装标识。确认运行前文件和审阅对象一致。
- [ ] 经授权后按三个目录 ID 逐一注册。先记录原安装目录和活跃项以支持回退。目标 ID 冲突时结束该套安装并确认来源。刷新后分别验证可选择、显示、切换、基础动画及减动开关。
- [ ] 按状态触发表记录观察和屏幕证据。用正常活动验证工作、审批等待、未读回报和安全失败样本。分别验证左右拖动和指针方向。挥手和跳跃若缺稳定触发条件，保留测试边界及离线动作证据。
- [ ] 退出并重启，复核三个 ID 仍可选择、图集哈希完整、原有宠物可选与回退有效。将每只的证据及遗留问题归档。

## P6｜私有 GitHub 与可恢复归档

- [ ] 经授权创建或接入私有 `rei-desktop-pet`。加入可交付的最终包、必要复算材料、工具版本、说明、清单及可分发资产。核定母版与角色 IP 权利及存放范围，冻结素材的同盘副本按授权纳入可恢复归档。
- [ ] 保存本地及授权备份的只读回滚点。复算交付文件 SHA-256，抽查从干净位置恢复三个包，确认版本和注册说明完整。推送后复核远端 commit 与内容，向主控提交 Git SHA、复算证据和剩余问题。

各阶段先完成前一阶段验收。工作区外部发布、换装调度、独立 Windows 程序以及 Codex 应用改造均不在 V1.0 范围内。
